App guide

Record speech, transcribe audio, and save text to OneDrive. This guide can stay open while the app works.

Getting started

  1. Import Key: sign in to Google Drive and enter the password for your existing encrypted Soniox key backup. The key is kept in this tab’s session.
  2. Connect Microsoft: use Link for email commands, or Devices → Connect this tab for control between computers. Use the same Microsoft account on each computer.
  3. Allow microphone access when asked. Use Start locally, or enable audio in Devices before starting remotely.

Recording buttons

Pause / ResumePauses audio capture, then continues the same recording. The button changes to Resume while paused.

Timer and VAD: the timer shows elapsed time, including pauses. Voice activity detection shortens the audio sent for transcription. The downloaded FLAC restores removed intervals as efficiently stored silence, so playback follows the full recording timeline, including pauses. Sound discarded by VAD is not restored.

History: select a recording to see its date, start, stop, elapsed time and retained audio duration. History stores those details, not a playable audio archive.

Stop and transcribe

Send this command by email or use it in Devices. It:

  1. Finishes the current recording and prepares its full-length FLAC download in the background.
  2. Starts a fresh recording once the previous audio has been finalized.
  3. Transcribes the previous audio with speaker labels in the background, then uploads the finished TXT to both Original (Transcripts) and temp in OneDrive.

The TXT filename includes the complete recording interval and the audio duration after VAD. Approving or blocking the local download does not control transcription or the transcript upload. A Soniox key and Microsoft connection are needed for the full workflow.

To finish recording without an automatic restart, use ordinary Stop.

Email commands

Click Link, then send an email from yourself to yourself using that Microsoft account. Leave the subject empty. Put only one command in the body, without a signature:

Email bodyAction
startStart recording.
pausePause recording.
resumeContinue the paused recording.
stopFinish and download, with no automatic restart.
stop and transcribeFinish, restart recording, transcribe and upload the previous recording.
abort recordingDiscard the current recording immediately, without saving, transcribing or restarting. Earlier background jobs continue.

Capital letters do not matter. The first four commands also accept recording at the end, for example Start recording. Only new emails received after linking and within the last two minutes are eligible.

Email can affect every computer linked to that mailbox; use Devices to target one tab. Unlink stops email monitoring. Unlike the local Abort button, the exact abort recording email command needs no extra confirmation.

Devices: control a particular tab

  1. Open Devices on each computer and connect each tab using the same Microsoft account. Give tabs clear names, such as Home PC and Work PC.
  2. Enable audio here prepares the tab you are currently using for remote recording. Click it locally on the computer you want to record with. It does not start recording.
  3. Select a tab in the list, then choose Start, Pause, Resume, Stop, Stop and transcribe, or Abort. Buttons enable when appropriate for that tab’s current state.

Status updates about every five seconds; Refresh also fetches the latest status and command results. Commands expire after 60 seconds.

Presence expires after ten seconds without an update. Connected tabs delete expired status files from OneDrive. If every tab was closed, cleanup resumes when a tab next connects. Each session updates one status file; separate tabs have separate entries.

Close only closes this window. Disconnect stops this tab’s Devices connection. Recording commands leave the connection active, including after Stop or Abort.

Transcribe a file

Use Upload File to select audio, choose whether you want Speaker labels (on by default), then press Transcribe. The app runs voice activity detection locally first and sends only retained speech to Soniox. If no speech is detected, nothing is uploaded. Results appear in the transcript field. You can edit that text and save it with EX.Drive.

With speaker labels enabled, recordings made by this app can show original clock times beside speaker turns, even after VAD removed silence. In a full-length FLAC, subtract its recording start time to find the matching playback position in VLC or another player.

Every manual transcription runs VAD, including WAV and FLAC files from other recorders. App-generated FLACs first recover the audio kept by the original VAD, then run the manual VAD pass. Existing clock metadata is preserved through further trimming; files without it do not gain original clock times. Preparation can take several minutes for long files. A decoding or VAD failure stops the upload so the full file is never submitted as a fallback. If full-length recording export fails, the app preserves the shortened WAV and shows a download warning.

Clear beside Import Key removes the Soniox key from this tab’s session after confirmation. It does not delete Drive files.

OneDrive files

The app uses its own OneDrive app folder. Original (Transcripts), translations and temp hold saved text; DeviceControl contains temporary device status, commands and replies. Audio downloads are saved locally, not uploaded to OneDrive by this app.

ButtonWhat happens
EX.DriveChoose one or more folders: Original (Transcripts), translations and temp. Saves the current text to each selected folder as a new timestamped TXT. Stop and transcribe automatically saves to both Original and temp, using the recording interval and VAD duration.
Imp. DriveChoose which folders to import. Then choose insert COMPLETE.txt into the transcript field, download ZIP, or both. These two output options are checked by default. Multiple folders are combined with folder headings; the ZIP preserves each folder and includes a combined COMPLETE.txt. Inserting replaces the current transcript field. With no folders or no output options selected, the button becomes Exit. The red × also closes the prompt.
Clear DriveChoose which folders to clear, then confirm deletion. Deletes only TXT files directly inside those folders. Unselected folders, subfolders, other files and device status are kept.

COMPLETE.txt is assembled during import from the saved text files in chronological order. The imported individual text copies and COMPLETE.txt include filename headings above their text.

Privacy view and closing the app

The small green button switches to a static Translator screen. Use the adjacent field and your privacy return code to switch back. Its example buttons do not control the real app.

Privacy view and this guide only change what is visible. Recording, email and device commands, transcription, automatic restart and OneDrive uploads continue behind them.

Keep the tab open until recording and processing have finished. Closing or reloading can interrupt recording and unfinished jobs; history does not preserve the recorded audio.

If something does not work

  • No remote Start: check the target tab is connected and recently seen, enable audio on that computer, and allow microphone access when asked.
  • No email action: check Link, the self-addressed sender and recipient, the empty subject and the exact body command.
  • Transcription failed: check the Soniox key and connection. The most recently processed audio stays selected for a manual retry while this tab remains open.
  • Automatic upload failed: the transcript remains in the output field. Reconnect Microsoft if needed, then use EX.Drive to save a copy.
  • Download prompt: the browser may ask before saving a local file. The automatic transcription workflow does not wait for that approval.
